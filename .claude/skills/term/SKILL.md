# 용어 설명: $ARGUMENTS

`docs/TERMS.md` 의 작성 규칙은 "정의 / 내 코드 / 면접 질문" 세 칸을 사용자가 **직접** 채우는 것이다 (README 진행 규칙 3). 그래서 이 스킬은 파일을 수정하지 않고, 사용자가 자기 말로 옮겨 적을 수 있는 초안을 채팅으로 준다.

## 절차

1. 이 저장소에서 용어가 실제로 쓰이는 곳을 찾는다 (`grep -rn` 으로 `src/`, `prisma/`, `scripts/`, `docker-compose.yml`, `docs/`). 없으면 "아직 코드에 없음, N단계에서 등장" 이라고 적는다.
2. `docs/TERMS.md` 의 단계별 체크리스트에서 이 용어가 어느 단계의 어느 항목인지 찾는다.
3. 아래 형식으로 답한다. 입문자 기준으로 비유 하나와 반대 개념 하나를 곁들이고, 영어 원어를 괄호로 병기한다. 한 번에 한 용어만 다룬다.

## 출력 형식

```
### <용어> (<English>)
- 정의: 두 문장 이내. 무엇이고 왜 필요한가.
- 내 코드: <파일:줄> — 그 줄이 이 개념의 어느 부분인지 한 문장. (아직 없으면 등장할 단계와 파일)
- 면접 질문: 질문 하나 + 답의 뼈대 두세 줄 + 흔한 오답 하나.
- 함께 볼 용어: 1~2개 (TERMS.md 체크리스트 기준)
- 단계: n단계 체크리스트 "<항목명>"
```

마지막에 한 줄: "TERMS.md 에 옮겨 적을 때 세 칸 중 못 채우는 칸이 있으면 그 부분을 다시 물어보세요."
