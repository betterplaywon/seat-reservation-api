# 헬스체크

- 규칙: 없음 (운영용 엔드포인트). `src/health/**` 는 완성본이다.
- 준비: MySQL 컨테이너만 있으면 된다. `SELECT 1` 만 하므로 테이블이 없어도 통과한다.

## 시나리오

1. `curl -s -w '\n%{http_code}\n' localhost:3011/health` → 200, `{"status":"ok","db":"ok","timestamp":"…"}`
2. MySQL 컨테이너를 멈춘 상태에서는 `db` 가 `ok` 가 아니어야 한다. 컨테이너를 멈추는 확인은 사용자가 요청했을 때만 한다.
