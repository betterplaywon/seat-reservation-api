# 1~2단계 학습 영역

이 파일들은 README 진행 규칙 1 에 따라 **사용자가 AI 없이 직접 작성**하는 곳이다 (층·좌석 조회, 스키마의 인덱스·제약 설계, EXPLAIN 실험).

- `TODO [1단계]`, `TODO [2단계]` 의 구현을 대신 쓰지 않는다. 대신 할 수 있는 것: 공식 문서 위치 안내, 개념 설명, 사용자가 쓴 코드 리뷰, 실패 원인 설명.
- 예외: `docs/REVIEW.md` 항목(7·8·9번 등)처럼 스캐폴딩 자체의 결함을 고치는 작업은 사용자가 그 항목을 진행하자고 했을 때만 한다. 그때도 어떤 줄을 왜 바꾸는지 먼저 설명한다.
- 편집 훅이 이 경로를 건드리기 전에 한 번 더 확인을 요청한다. 사용자의 학습 기회를 지키기 위한 것이지 오류가 아니다.
