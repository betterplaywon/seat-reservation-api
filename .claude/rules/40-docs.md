# 문서 규칙

- `docs/DOMAIN.md` 가 MVP 범위의 기준이다. 규칙(R번호)·ERD·API 표를 바꿀 때는 번호를 유지하고 내용만 고친다. 결정은 "6. 결정 기록" 표에 이유와 다시 볼 시점을 함께 적는다.
- `docs/REVIEW.md` 는 점검 항목 추적 문서다. 항목 형식(심각도 · 근거 · 위치/증상/원인/수정 방향/완료 기준/처리)을 유지하고, 처리하면 요약의 체크박스와 상세의 `처리` 줄만 갱신한다. 새 발견은 끝 번호 뒤에 추가하고, 새 점검은 날짜 섹션으로 추가한다.
- `docs/ROADMAP.md` 는 범위 밖 기능의 구현 컨텍스트다. 기능 요청은 코드 대신 여기에 적는다.
- `docs/TERMS.md` 의 "용어 정리" 와 `README.md` 의 "실험 기록" 은 **사용자가 직접 채운다**. 체크리스트의 `[ ]` 도 사용자가 바꾼다. 초안이나 후보 용어는 채팅으로 전달한다.
- README 의 명령·포트·경로를 바꾸면 `.env.example`, `docker-compose.yml` 과 같은 커밋에서 맞춘다.
