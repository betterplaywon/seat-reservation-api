# 용어 노트

## 작성 규칙

용어 하나당 아래 세 칸을 채운다. 하나라도 못 채우면 아직 모르는 것이다.

```
### 커넥션 풀
- 정의: DB 연결을 미리 여러 개 만들어두고 재사용하는 묶음. 매 요청마다 연결을 새로 맺는 비용을 줄인다.
- 내 코드: src/prisma/prisma.service.ts — Prisma 가 내부적으로 관리. DATABASE_URL 의 ?connection_limit=N 으로 조절.
- 면접 질문: 풀 크기를 늘리면 항상 빨라지나? → MySQL max_connections, CPU 코어 수와 함께 답할 것.
```

## 단계별 용어 체크리스트

해당 단계에서 아래 용어가 코드에 안 나오면 뭔가 빠진 것이다. 채운 용어는 `[x]` 로 바꾼다.

### 1단계 — 셋업·NestJS 구조
- [ ] 런타임 / 이벤트 루프
- [ ] 모듈 / 프로바이더 / 의존성 주입(DI)
- [ ] 싱글턴
- [ ] 데코레이터
- [ ] 미들웨어 vs 가드 vs 인터셉터 vs 파이프 (실행 순서)
- [ ] 환경변수 / 시크릿
- [ ] Docker 이미지 / 컨테이너 / 볼륨
- [ ] 공급망 공격 (pnpm 이 설치 스크립트를 막는 이유)

### 2단계 — DB 모델링·조회
- [ ] 스키마 / PK / FK
- [ ] 정규화 (1~3NF)
- [ ] ERD
- [ ] 마이그레이션
- [ ] DATE 타입 / 타임존 / UTC (왜 날짜를 문자열로만 주고받는가)
- [ ] 조인 (INNER / LEFT)
- [ ] 인덱스 (B-tree / 복합 / 커버링)
- [ ] 카디널리티 / 선택도
- [ ] EXPLAIN (type / key / rows / Extra)
- [ ] N+1 문제 (include vs 반복 조회)
- [ ] 벌크 insert (createMany) / 배치

### 3단계 — 인증·인가
- [ ] 해싱 vs 암호화
- [ ] 솔트 / bcrypt cost factor
- [ ] JWT 구조 (헤더 / 페이로드 / 서명)
- [ ] 액세스 토큰 / 리프레시 토큰
- [ ] Bearer / Authorization 헤더
- [ ] 인증 vs 인가 (401 vs 403)
- [ ] RBAC
- [ ] 쿠키 vs 헤더 토큰 / CORS / CSRF

### 4단계 — 예약 생성 (핵심)
- [ ] 트랜잭션 / ACID
- [ ] 커밋 / 롤백
- [ ] 격리 수준 4단계
- [ ] 더티 리드 / 논리피터블 리드 / 팬텀 리드
- [ ] 락 (공유 / 배타, 행 / 테이블, 갭 락)
- [ ] SELECT FOR UPDATE (왜 "없는 행"이 아니라 부모 행을 잠그는가)
- [ ] 데드락 / 락 순서 (lock ordering)
- [ ] 유니크 제약 / 유니크 인덱스와 NULL (조건부 유니크가 없을 때)
- [ ] 낙관적 락 vs 비관적 락
- [ ] 레이스 컨디션 / check-then-act
- [ ] 멱등성
- [ ] 소프트 삭제 / 상태 전이
- [ ] 소유권 검증 (403 vs 404)

### 5단계 — 검증·에러·로깅
- [ ] DTO
- [ ] 직렬화 / 역직렬화
- [ ] HTTP 상태코드 (400 / 401 / 403 / 404 / 409 / 422 / 500 / 503)
- [ ] 예외 필터
- [ ] 구조화 로깅 / 요청 ID
- [ ] 헬스체크

### 6단계 — 배포·운영
- [ ] 빌드 vs 런타임
- [ ] 포트 / 리버스 프록시 / TLS
- [ ] 프로세스 매니저
- [ ] 무중단 배포
- [ ] 타임아웃
- [ ] 부하 테스트 (RPS / p95)
